# Caja Huanaco · BKF y Munich Knits

Punto de venta para las ferias Barcelona Knit Festival y Munich Knits.
Efectivo, transferencia (IBAN y QR SEPA) y PayPal (QR con importe o con tarjeta).

Archivos: `index.html` (la app) y `sw.js` (para que funcione sin conexión).
Si cambiás `index.html`, subí también `sw.js` con el número de versión aumentado.
No borres el ícono de la pantalla de inicio en iOS: borra las ventas guardadas.
